# EcoPulse Carbon — Footprint Tracking & Reduction Services

A responsive web application built using **CSS Flexbox navigation architecture** (`display: flex`, `flex-direction`, `justify-content`, `align-items`, and `flex-wrap`), featuring an interactive **Plans** dropdown (`Freelancer`, `Startup`, `Enterprise`), live CO₂e footprint estimator, and authentication modals.

## Unique Project File Structure
- `index.html` — Main entry point (required by GitHub Pages & Vercel)
- `ecopulse-flex-layout.css` — Custom Flexbox navigation & responsive sustainability theme
- `carbon-telemetry-engine.js` — Interactive CO₂e calculator, dropdown controller, and modal logic
- `vercel.json` — Vercel static deployment configuration

## Quick Deploy to GitHub & Vercel
1. Create a new repository on GitHub (e.g., `ecopulse-carbon-portal`).
2. Upload all files from this folder to the root of your repository.
3. Log in to [Vercel](https://vercel.com), click **Add New → Project**, import your GitHub repository, and click **Deploy**.
